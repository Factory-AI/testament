# Exact-byte prototype

Informative, disposable research for `RES-PROTOTYPE-EXACT-BYTE-001`.
The runner round-trips empty, malformed, invalid UTF-8, CRLF, binary, provider,
and giant fixture bytes without decoding. Results are filesystem-custody
evidence, not an HTTP transfer-framing claim. The active
[version 2 result](../../docs/research/benchmarks/v2/exact-byte.json) contains
three externally resource-accounted samples from the shared
[clean-clone rerun](../../docs/research/benchmarks/v2/reproduction.json).
The [version 1 result](../../docs/research/benchmarks/exact-byte.json) remains
queryable only as superseded evidence.
