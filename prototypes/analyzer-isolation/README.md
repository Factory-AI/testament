# Analyzer-isolation prototype

Informative, disposable research for
`RES-PROTOTYPE-ANALYZER-ISOLATION-001`. A child receives bounded CPU, address
space, descriptors, deadline, output, environment, and working directory.
The result deliberately records that a plain subprocess does not prove network
denial, so it is rejected as the complete hostile-extension boundary. The
active
[version 2 result](../../docs/research/benchmarks/v2/analyzer-isolation.json)
contains three descendant-tree-accounted samples from the shared
[clean-clone rerun](../../docs/research/benchmarks/v2/reproduction.json).
The [version 1 result](../../docs/research/benchmarks/analyzer-isolation.json)
remains queryable only as superseded evidence.
