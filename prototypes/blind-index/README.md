# Blind-index prototype

Informative, disposable research for `RES-PROTOTYPE-BLIND-INDEX-001`.
The runner compares HMAC-SHA-256 equality tokens across organization, field,
and generation scopes. It records the unavoidable equality and frequency
leakage within one scope and makes no full-text, range, or prefix-search claim.
The active [version 2 result](../../docs/research/benchmarks/v2/blind-index.json)
contains three externally resource-accounted samples from the shared
[clean-clone rerun](../../docs/research/benchmarks/v2/reproduction.json).
The [version 1 result](../../docs/research/benchmarks/blind-index.json) remains
queryable only as superseded evidence.
