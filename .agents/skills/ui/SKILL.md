# UI

## Scope

Use for embedded console or static standards-site work after their application
contracts exist.

## Entry points

Read the public design and API contracts, add a failing component or browser
case, build the real surface, and verify it with the designated browser tool.

## Recovery

Stop only the declared service, run `make doctor`, correct the structured
failure, rebuild, and repeat accessibility, console, and network observations.

## Boundaries

Use approved ports only. Render arbitrary content as text, mask sensitive data,
preserve keyboard access, and add no remote fonts, analytics, or hidden egress.
