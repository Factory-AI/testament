# Research

## Scope

Use for studies, evidence ledgers, corpus research, prototypes, benchmarks, and
independent review records. Mark observation, inference, uncertainty, status,
owner, reviewer, and supersession explicitly.

## Entry points

Read `docs/research/README.md`, add a failing registry or evidence-coverage
test, then run `make verify-research`, `make verify-claims`, and
`make test-gate`.

## Recovery

Use the structured failing path and remediation. Restore source links or
manifest lineage, rerun generation if declared, and rerun the focused check.

## Boundaries

Research is informative unless an accepted RFC says otherwise. Use no customer
data, private-only evidence, external inference, or unsourced pass claim.
